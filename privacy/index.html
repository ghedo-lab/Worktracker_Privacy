1. Come funziona WorkTracker

WorkTracker è un'app di timbratura ore lavoro e gestione trasferte aziendali pensata per funzionare con un server auto-ospitato (self-hosted): ogni organizzazione installa ed amministra il proprio server, e l'app comunica solo con quel server, scelto dall'utente/amministratore in fase di associazione.

Lo sviluppatore dell'app non riceve, non ospita e non ha accesso ai dati di lavoro, spostamento o spesa inseriti nell'app: quei dati restano sul server scelto dall'organizzazione che lo gestisce. Il titolare del trattamento di quei dati è l'organizzazione/datore di lavoro che gestisce il proprio server, non lo sviluppatore.

Se usi WorkTracker per lavoro, per domande sui dati trattati dal tuo datore di lavoro tramite il server aziendale, rivolgiti al tuo referente aziendale, non allo sviluppatore.

3. Dati raccolti dall'app e da servizi terzi

Modalità Offline: tutti i dati restano esclusivamente sul dispositivo. Nessun dato di lavoro viene trasmesso a server dello sviluppatore o di terzi.

Modalità Online: i dati vengono sincronizzati con il server scelto dall'amministratore dell'organizzazione. Non esiste un server centralizzato gestito dallo sviluppatore per i dati di lavoro.

Permessi del dispositivo richiesti

  • Fotocamera/galleria: per foto scontrini (OCR) e screenshot di supporto opzionali
  • Rete locale: per scoprire e comunicare con il server auto-ospitato
  • Notifiche: per eventi di sincronizzazione (se configurati)

L'app non richiede né usa l'accesso alla posizione GPS precisa: gli indirizzi sono digitati manualmente e geocodificati tramite Photon.

4. Conservazione e cancellazione dei dati

I dati sul dispositivo restano fino alla disinstallazione o cancellazione manuale. Le cancellazioni sul server vengono conservate come "tombstone" per un periodo limitato (attualmente 90 giorni) per la sincronizzazione tra dispositivi, poi rimosse fisicamente in automatico.

5. Nessuna pubblicità, nessuna vendita di dati

WorkTracker non contiene pubblicità e non vende né condivide dati con terzi a scopo commerciale o pubblicitario.

6. I tuoi diritti (GDPR)

Hai diritto di accedere, rettificare, cancellare i tuoi dati personali, nonché di opporti al trattamento o richiederne la portabilità (artt. 15-22 GDPR). Per i dati sul server della tua organizzazione, contatta il tuo amministratore. Per i dati trattati dai servizi terzi elencati sopra, contatta lo sviluppatore.
