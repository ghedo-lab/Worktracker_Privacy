Cos'è WorkTracker

WorkTracker è un'app Android per la gestione di ore lavorate, trasferte aziendali e spese, pensata per piccole e medie organizzazioni. A differenza della maggior parte delle app simili, WorkTracker non si appoggia a un servizio cloud gestito da terzi: ogni organizzazione ospita il proprio server (anche su un semplice Raspberry Pi), mantenendo pieno controllo sui propri dati.

📍 Trasferte e note spese
🧾 Report ed export Excel/PDF
📷 Scansione scontrini (OCR)
🔒 Server auto-ospitato
📶 Funziona anche offline

Piani

WorkTracker si rivolge sia a singoli professionisti sia a organizzazioni con un proprio server.

Individuale

Per un singolo utente, in modalità Offline sul proprio dispositivo. Include un periodo di prova gratuito.

Server — Small

Per organizzazioni fino a 50 utenti totali. Trasferte e report inclusi.

Server — Base

Per organizzazioni fino a 100 utenti totali. Trasferte e report inclusi.
